## Repository purpose

This repository is the owner's Agent Kit, a reusable agent harness they can share and use across their projects.

## Repository layout

The repository root holds the shared kit: skills, configuration, and the development workflow.

- [`.agents/skills/`](.agents/skills/) contains the shared agent skills. Read the relevant `SKILL.md` before applying a skill.
- [`docs/agents/`](docs/agents/) contains project guidance on issue tracking, triage labels, and domain documentation.
- [`cases/`](cases/) holds individual cases. Use each case folder for its solutions and glossary.
  - For work on the Process Panel, read the [case instructions](cases/process-panel/AGENTS.md).

## Language

Write agent-facing files in English. Write each case's `GLOSSARY.md` in Russian.

## Agent skills

### Issue tracker

Use GitHub Issues for project tasks. See `docs/agents/issue-tracker.md` for commands.

### Triage labels

When triaging issues, use the label mapping in `docs/agents/triage-labels.md`.

### Domain docs

When exploring a case, use the glossary layout in `docs/agents/domain.md`.
