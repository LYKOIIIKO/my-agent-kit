# Панель процессов

Здесь собраны термины панели для управления запусками локальных проектов.

## Термины

**Панель процессов**

Веб-страница со списком **запусков проектов** и их статусами. Владелец управляет запусками из этой страницы.

**Запуск проекта**

Одно выполнение команды `npm run dev` для локального проекта. У проекта может быть несколько одновременных запусков.

**Настройки запуска**

Данные для повторного **запуска проекта**. В них входят рабочая папка, аргументы команды и нужные для запуска переменные окружения.

**Работает**

Статус активного **запуска проекта**. Панель показывает его и во время начальной сборки.

**Остановлен**

Статус завершённого **запуска проекта**.
