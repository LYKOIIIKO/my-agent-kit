# Панель процессов — итоги обсуждения

**Поведение первой версии согласовано.** Панель нужна, чтобы находить забытые локальные запуски и освобождать занятые ими порты. Она также позволяет перезапустить работающий проект или снова запустить уже остановленный.

## Что показывает панель

- Веб-страница доступна на том же компьютере. Панель работает с обычными правами владельца и показывает запуски его учётной записи Windows.
- Панель сама находит подтверждённые запуски `npm run dev` из PowerShell и терминала VS Code. Она видит и те запуски, которые появились до открытия страницы.
- У каждого запуска своя строка со статусом и портами. Если один проект запущен дважды, у него две отдельные строки. Панель обновляет список, статусы и порты автоматически.
- «Работает» означает, что запуск активен. Этот статус виден уже во время начальной сборки.

## Как управлять запуском

- **Остановить.** Панель завершает выбранный запуск и процессы, принадлежность которых к нему подтверждена. Если мягкая остановка недоступна или не удалась, панель предлагает принудительное завершение и ждёт подтверждения.
- **Перезапустить.** Панель проверяет настройки запуска, затем останавливает текущий запуск. Новый запуск начинается после успешной остановки. При ошибке остановки панель отменяет перезапуск и показывает ошибку.
- **Запустить снова.** После завершения строка остаётся со статусом «Остановлен» до перезагрузки страницы. С известными настройками можно запустить проект из той же строки. Если новый запуск не удался, панель сохраняет строку, показывает ошибку и короткий фрагмент вывода, если он доступен, и предлагает повторить попытку.

Запуски из панели работают в фоне и продолжаются после закрытия вкладки. При следующем открытии панель снова найдёт активные запуски.

## Настройки запуска

Для перезапуска и повторного запуска нужны рабочая папка, аргументы `npm run dev` и необходимые переменные окружения. Если каких-то данных не хватает, их можно указать в строке. Панель хранит введённые данные для этой строки до перезагрузки или закрытия страницы. Подтверждённый запуск можно остановить и при неизвестных настройках.

## Стек и запуск

Для веб-интерфейса выбрали **Vue 3, TypeScript и Vite**.
Для локального сервера выбрали **Node.js и Fastify**.

Первую версию запускаем из репозитория на Windows. В ближайших версиях расширяем функции Панели на одном компьютере.

## Открытые вопросы

Прототип на Node.js и Fastify нашёл два пробных запуска одного проекта. Один запустили в PowerShell, второй во встроенном терминале VS Code. Прототип показал TCP-порт каждого запуска. После подтверждения принудительной остановки порт запуска из VS Code освободился, а запуск из PowerShell продолжил отвечать.

Предстоит проверить условия мягкой остановки и завершение всех подтверждённых процессов у обычных проектов.
